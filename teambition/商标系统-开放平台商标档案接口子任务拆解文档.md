# 开放平台商标档案接口 - 子任务拆解

> 本文档依据《开放平台商标档案接口接入文档》整理，沿用《接口子任务拆解文档》的结构。每行代表一个父任务；单元格内编号可直接创建为子任务，“父任务验收”是关闭该父任务的最低条件。

| 父任务 | 子任务 | 父任务验收 |
| --- | --- | --- |
| 0. 开放平台接入项目初始化 | 0.1 确认四个接口的接入范围。<br>0.2 确认各环境地址、网络、HTTPS 和白名单。<br>0.3 建立联调联系人、变更和上线安排。<br>0.4 输出接口与环境配置清单。 | 接入范围、环境和上线计划已确认；测试环境可访问平台。 |
| 1. 租户与密钥配置 | 1.1 申请 appKey 并确认绑定租户。<br>1.2 获取并校验平台 RSA 公钥。<br>1.3 生成客户密钥对并向平台提供公钥。<br>1.4 将地址、密钥和业务配置接入环境变量或密钥服务。<br>1.5 排查代码和日志中的敏感信息。 | appKey 与租户匹配；双方密钥可用；敏感配置未明文入库。 |
| 2. 通用安全协议客户端实现 | 2.1 生成 AES-128 密钥和 nonce。<br>2.2 实现 AES 加密及 RSA 加密 AES 密钥。<br>2.3 组装外层请求字段。<br>2.4 按排序后的紧凑 JSON 签名。<br>2.5 实现响应验签与解密。 | 可正确加密请求、验签并解密响应；签名规则符合协议。 |
| 3. 商品/服务项大类查询接入 | 3.1 开发 `/openApi/tm/goods/clses` 调用。<br>3.2 校验 cgNum 输入范围。<br>3.3 解析 cgId 和大类必要字段。<br>3.4 保存原始大类数据。<br>3.5 联调指定与全量查询。 | 可稳定取得大类；后续流程正确使用 cgId。 |
| 4. 按大类查询商品/服务项接入 | 4.1 开发 `/openApi/tm/goods/listByCgId` 调用。<br>4.2 支持 containThree 参数。<br>4.3 保存类似群和商品项字段。<br>4.4 校验商品项与 tmCl 同类。<br>4.5 联调无效 cgId 和三级数据场景。 | 可按 cgId 查询商品项；商品数据可用于组装 goodsItemCn。 |
| 5. 文件上传接口接入 | 5.1 开发 multipart 请求，字段名为 file。<br>5.2 复用安全字段及上传签名规则。<br>5.3 处理文件缺失、为空、无文件名错误。<br>5.4 解密响应并提取 fileKey。<br>5.5 使用 fileKey 设置 tmImage。 | 可上传文件并获得 fileKey；fileKey 可用于建档。 |
| 6. 商标档案创建核心实现 | 6.1 开发 `/openApi/tm/create` 加密调用。<br>6.2 实现 requestId 幂等与重试。<br>6.3 校验必填业务字段。<br>6.4 将商品项作为 JSON 字符串传入。<br>6.5 解析创建成功响应。<br>6.6 联调重复、申请人和商品项异常。 | 不重复建档；可返回档案标识；关键校验错误可识别。 |
| 7. 自定义字段与可选业务字段适配 | 7.1 映射图样、日期、地址、状态等可选字段。<br>7.2 校验马德里申请日期规则。<br>7.3 按租户配置组装 customFields。<br>7.4 校验文本、选项、附件、日期和数字字段。<br>7.5 联调字段配置和类型异常。 | 可选字段符合规则；自定义字段错误可定位。 |
| 8. 响应处理、异常恢复与可观测性 | 8.1 分层判断 HTTP、errorCode、验签、解密和 resultCode。<br>8.2 映射常见 14xx 与 1001 错误。<br>8.3 对安全场景重试，建档复用 requestId。<br>8.4 记录调用结果，脱敏敏感信息。<br>8.5 配置失败告警和排查入口。 | 不会将 HTTP 200 误判为成功；失败可定位且重试不重复建档。 |
| 9. Java 示例、配置与自动化测试 | 9.1 封装 `OpenPlatformClient` 公共能力。<br>9.2 串联四个接口的示例流程。<br>9.3 锁定 JDK 8 与 Fastjson 依赖。<br>9.4 覆盖加密、签名、验签、商品组装和重试测试。<br>9.5 用环境变量运行示例。 | 示例可完成测试环境全流程；核心逻辑具备自动化测试。 |
| 10. 联调、验收与生产上线 | 10.1 联调四个接口的正常流程。<br>10.2 联调签名、密钥、租户、商品项和文件异常。<br>10.3 验证先验签、再解密、再判业务结果。<br>10.4 核验建档、文件关联、幂等和日志。<br>10.5 评审 HTTPS、密钥轮换、监控和回滚。 | 正常及异常场景通过验收；安全、租户、幂等和文件关联满足上线条件。 |
