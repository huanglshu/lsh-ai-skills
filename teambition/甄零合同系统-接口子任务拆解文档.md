# 甄零合同系统奥飞对接接口 - 子任务拆解

> 本文档从《甄零合同系统奥飞对接接口-任务拆解清单》中复制“接口子任务拆解（可直接创建）”内容。每行代表一个父任务；单元格内编号可直接创建为子任务，“验收”是父任务关闭的最低条件。

| 父任务 | 子任务 | 父任务验收 |
|---|---|---|
| 0. 甄零合同系统中转服务（alphax-contract-transfer）初始化 | 0.1 确认服务职责边界、接口路由、调用方清单、环境规划和配置项清单。<br>0.2 初始化工程构建、应用启动、模块结构及本地/测试/生产环境配置模板。<br>0.3 配置数据源、Redis、外部系统地址、密钥引用和连接健康检查；敏感信息不得写入代码或文档。<br>0.4 接入统一鉴权、请求 ID、异常响应、调用日志、任务调度和监控告警等公共能力。<br>0.5 完成测试环境部署、基础接口冒烟、依赖连通性检查和回滚验证。 | 服务可在测试环境稳定启动；健康检查、日志、监控、鉴权和配置管理可用；具备可执行的部署与回滚步骤。 |
| 1. PS 企业组织（部门）全量同步 | 1.1 确认部门编码、父级编码、组织层级、启停用及空父级处理规则。<br>1.2 实现 PS 全量分页拉取和响应转换。<br>1.3 按部门编码执行新增、更新、失效处理，保留层级校验失败记录。<br>1.4 配置每日 01:00 调度、失败重跑和全量对账。<br>1.5 以生产样例完成组织树、数量和失效部门对账。 | 组织层级正确，部门编码唯一，首批全量数据可追溯。 |
| 2. PS 人员增量同步 | 2.1 确认工号唯一性、所属部门/岗位关联、离职和调岗语义。<br>2.2 实现按创建时间、更新时间的增量游标及分页拉取。<br>2.3 实现人员新增、更新、离职失效，处理部门未同步的暂存/重试。<br>2.4 配置每小时调度、游标保存与补数入口。<br>2.5 验证新增、调岗、离职、重复数据及跨窗口更新场景。 | 人员总数和关键字段对账一致，离职人员不可继续作为有效人员使用。 |
| 3. PS 岗位全量同步 | 3.1 确认岗位编码、名称、部门归属和启停用规则。<br>3.2 实现岗位全量拉取、分页和字段映射。<br>3.3 执行岗位 upsert 及失效处理，校验组织和人员引用。<br>3.4 配置每日调度、对账和异常告警。<br>3.5 验证岗位变更、停用和人员岗位关联。 | 岗位主数据及关联关系与 PS 对账一致。 |
| 4. OC 审批待办推送与撤回 | 4.1 明确待办创建、更新、撤回、已办的状态机和 PC/企微字段差异。<br>4.2 开发合同审批事件触发、待办报文组装和 OA 推送。<br>4.3 实现幂等键、失败重试、状态查询及人工补发。<br>4.4 联调审批创建、撤回、已办全链路。<br>4.5 灰度验证 PC 与企微待办状态一致。 | 同一审批事件只生成一条有效待办，撤回和已办状态可双端对账。 |
| 5. OC 合同抄送推送 | 5.1 确认抄送触发节点、收件人来源、撤销和重复抄送规则。<br>5.2 开发抄送事件和 OA 报文适配。<br>5.3 实现幂等、失败补发和抄送状态查询。<br>5.4 联调 PC/企微抄送呈现及异常回执。 | 指定人员仅收到一次有效抄送，撤销规则符合双方约定。 |
| 6. OC 待办处理结果回传 | 6.1 明确回传事件、结果码、处理人、处理时间和状态映射。<br>6.2 开发 OA 回传调用及合同审批状态更新。<br>6.3 实现重复回传、乱序回传和失败补偿处理。<br>6.4 联调通过、拒绝、撤回后的状态回传。 | OA 和 OC 对同一待办的最终状态及处理人一致。 |
| 7. 企业微信待办应用配置 | 7.1 确认企微应用、可见范围、待办消息关闭策略及 OA 转发边界。<br>7.2 配置应用凭据、回调地址、IP 白名单和权限。<br>7.3 验证员工可访问应用且不接收 OC 重复待办消息。<br>7.4 输出配置记录、回退步骤和运维联系人。 | 企微应用可用，待办仅按确定链路投递。 |
| 8. OA 门户至 OC 单点登录 | 8.1 确认工号匹配、签名/令牌、有效期、登出和未匹配用户策略。<br>8.2 开发 OA 跳转 URL 校验、用户解析和 OC 静默登录。<br>8.3 实现消息、待办跳转后的目标页和权限校验。<br>8.4 验证 PC/企微、过期令牌、篡改参数和用户不存在场景。 | 合法 OA 用户可直达指定 OC 页面，非法或过期请求被拒绝并可回退。 |
| 9. Oracle 数仓供应商主数据接入 | 9.1 确认供应商主键、增删改动作码、批次号和期初数据口径。<br>9.2 开发接收接口、签名校验及 20 条批次的幂等处理。<br>9.3 实现新增、变更、删除和失败批次重放。<br>9.4 配置半小时监控、积压告警和 100 条期初对账。<br>9.5 联调新增、变更、删除、重复批次和部分失败场景。 | 批次可重放且不重数，期初和增量数据均完成对账。 |
| 10. Oracle 数仓我方公司主数据接入 | 10.1 确认公司主数据权威来源、公司编码、启停用和推送频率。<br>10.2 完成字段映射、接收契约和幂等键设计。<br>10.3 开发公司新增、更新、失效处理。<br>10.4 联调并完成公司编码、状态和数量对账。 | 对接方案确认后，公司主数据可稳定更新且不影响已有合同。 |
| 11. Oracle 数仓客户主数据接入 | 11.1 确认客户唯一标识、名称变更、合并、失效及黑名单规则。<br>11.2 完成字段映射、接收接口和幂等设计。<br>11.3 开发新增、变更、合并/失效的业务处理。<br>11.4 联调并验证客户被合同引用后的历史数据保留。 | 客户主数据不重不漏，变更不会破坏历史合同引用。 |
| 12. OA 经销商目标批量接入 | 12.1 确认目标编码、经销商关联、年度/期间和新增更新规则。<br>12.2 开发批量接收、签名校验和批次级事务控制。<br>12.3 实现按编码 upsert，任一行失败时整批回滚并返回明细。<br>12.4 联调整批成功、单行非法、重复批次和更新场景。 | 一批次严格全成或全败，结果明细可定位到错误数据行。 |
| 13. Oracle 数仓币种主数据接入 | 13.1 确认币种标准代码、名称、精度、启停用及默认币种规则。<br>13.2 开发币种接收和幂等更新。<br>13.3 校验币种被合同引用时的停用限制。<br>13.4 联调并完成代码、精度和状态对账。 | 币种代码唯一，精度满足合同金额计算要求。 |
| 14. Oracle 数仓汇率数据接入 | 14.1 确认币种对、汇率日期、生效时间、精度、覆盖和缺失规则。<br>14.2 完成接收契约及汇率唯一键设计。<br>14.3 开发新增/更正处理和历史汇率保留。<br>14.4 联调跨日期、重复推送、精度边界和缺失汇率场景。 | 指定日期可获取唯一、可追溯且精度正确的汇率。 |
| 15. Oracle 数仓 IP 项目段接入 | 15.1 确认项目段编码、名称、层级、启停用和合同标的行引用规则。<br>15.2 开发接收与幂等更新。<br>15.3 实现停用校验和历史合同引用保留。<br>15.4 联调项目段维护及合同标的行选择场景。 | 有效项目段可选择，停用项目段不影响历史合同。 |
| 16. 业务中台合同创建及结果回调 | 16.1 确认中台创建合同的必填字段、来源单号、去重键和回调时机。<br>16.2 开发合同基础信息接收、校验、创建及来源单号关联。<br>16.3 开发创建结果回调和跳转链接生成。<br>16.4 实现超时、重复推送、创建失败和回调失败的补偿。<br>16.5 联调创建、回调、跳转和重试全链路。 | 同一来源单只创建一份合同，调用方可获取可用的结果和跳转地址。 |
| 17. 授权系统授权类合同增量查询 | 17.1 确认授权类合同筛选、增量游标、变更版本和下游权限范围。<br>17.2 开发合同、标的、相对方等查询 API 及签名鉴权。<br>17.3 实现稳定分页、增量查询、版本标识和数据脱敏。<br>17.4 联调新增、变更、权限不足、分页和增量补拉。 | 下游仅能获取授权类的授权数据，增量无漏数、无重复。 |
| 18. 授权系统 IP 品类日同步 | 18.1 确认品类编码、名称、层级、启停用及与 IP 项目段的关联。<br>18.2 开发每日拉取、分页和字段转换。<br>18.3 实现 upsert、失效处理和异常记录。<br>18.4 联调并完成品类数量、编码和关联对账。 | IP 品类可正确用于合同业务选择，数据每日可稳定更新。 |
| 19. 授权系统媒体库数据接入 | 19.1 确认媒体唯一标识、元数据范围、文件访问方式及同步频率。<br>19.2 确认附件不落库/对象存储/链接引用的技术方案。<br>19.3 开发媒体元数据接收和文件授权访问。<br>19.4 联调媒体查询、失效和无权限访问场景。 | 方案确认后，媒体引用可访问、可追溯且无越权泄露。 |
| 20. 费控付款类合同及非收非支查询服务 | 20.1 明确归档完成判定、合同范围、履约计划、变更版本和取消归档规则。<br>20.2 开发下游拉取 API、权限控制、增量变量和稳定分页。<br>20.3 实现新增/变更数据输出，确保取消归档不触发更新。<br>20.4 联调归档、变更、取消归档、重新归档和增量补拉。<br>20.5 对账合同、履约行和金额字段。 | 费控可按规则获取完整数据，状态变更不产生错误更新。 |
| 22. 费控付款执行结果回写 | 22.1 确认履约行主键、结果状态、金额、时间和删除初始计划的触发条件。<br>22.2 开发回写接收、鉴权、幂等与请求校验。<br>22.3 实现固定金额合同总额与履约计划金额强校验。<br>22.4 实现非收非支变更后的初始履约行删除及审计。<br>22.5 联调重复回写、金额不一致、部分失败和回滚场景。 | 付款结果可准确落到履约行，金额不一致数据被拒绝且可追溯。 |
| 24. 档案系统合同附件授权查询 | 24.1 决策文件存储位置、附件类型、访问令牌、有效期和权限模型。<br>24.2 确认系统附件、归档附件、审批附件的查询范围与元数据。<br>24.3 开发附件清单查询、授权下载/预签名链接和审计日志。<br>24.4 开发分页、增量或版本查询，并处理文件不存在/无权限。<br>24.5 联调文件访问、权限隔离、过期链接和大文件场景。 | 档案系统仅能访问授权附件，文件访问记录可审计。 |
| 25. 经销商协议业绩目标批量制单 | 25.1 指定业务、开发、测试负责人并确认 B 系统数据获取方式。<br>25.2 确认协议筛选、业绩目标字段、合同模板占位符和写入规则。<br>25.3 开发协议批量处理、目标查询、模板填充及异常回滚。<br>25.4 验证多协议、缺失目标、重复执行和权限不足场景。<br>25.5 完成 UAT 和批量执行操作交接。 | 目标可准确写入对应模板，失败协议不污染已生成合同。 |
| 26. 预算系统预算申请单同步 | 26.1 校正排期后确认申请单主键、状态、金额、预算科目和关联规则。<br>26.2 确认拉取频率、增量游标、分页与撤回/作废处理。<br>26.3 开发预算申请单拉取、转换、幂等落库和补数。<br>26.4 验证新增、更新、作废、重复及关联合同场景。 | 预算数据可按确定频率同步，关联合同规则正确。 |
