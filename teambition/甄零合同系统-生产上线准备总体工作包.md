# 合同系统生产上线准备 - 总体工作包

> 本文档从《生产上线准备任务拆解》提取总体工作包，用于任务创建和范围确认。  
> 每行代表一个父任务；单元格内编号可直接创建为子任务，“验收”是父任务关闭的最低条件。负责人、计划日期和实际环境资料需由项目组补充确认。

| 父任务 | 子任务 | 父任务验收 |
|---|---|---|
| 1. 对象存储 OSS 合同附件补全 | 1.1 确认补全范围和排除清单。<br>1.2 按合同创建日期生成合同编码清单。<br>1.3 盘点 OSS 缺失附件及异常文件。<br>1.4 重传附件并处理非法文件名。<br>1.5 按 10 份/批重传，支持指定批次续跑。<br>1.6 记录失败合同并支持单独补传。<br>1.7 完成数量、文件和回滚验证。 | 补全范围内每个合同的附件目录及文件完整，失败清单闭环；重复执行不产生重复或错误覆盖；成功、失败及缺失数量与源系统对账一致，且具备按合同编码补传和回滚能力。 |
| 2. 相对方同步逻辑优化 | 2.1 确认字段、来源、黑名单和更新规则。<br>2.2 确认主体、角色及明细取数口径。<br>2.3 完善同步类型识别和排序。<br>2.4 修正客户来源判断。<br>2.5 按业务键完成明细去重。<br>2.6 统一定时任务和门户重推锁。<br>2.7 完善同步日志、进度和失败重推。<br>2.8 完成全量及增量对账。 | 相对方主体及角色、银行、联系人数据不重不漏；同一业务键结果唯一；定时任务与人工重推互斥；失败可定位、可重推；生产全量及关键字段对账通过。 |
| 3. 运维平台开发 | 3.1 完成相对方同步记录查询、详情和重推。<br>3.2 完成合同到中间库同步记录页面。<br>3.3 完成中间库到费控同步记录和重推。<br>3.4 接入菜单、权限和审计。<br>3.5 完成并发、重复点击及异常测试。<br>3.6 发布生产并完成运维交接。 | 三类同步记录均可查询和追溯；相对方及费控失败记录可按原业务键安全重推；重复点击不产生重复业务数据；报文可读取和复制；权限、审计、告警及运维手册齐备。 |
| 4. 经销商目标批量录入功能优化 | 4.1 冻结字段、枚举、金额和唯一键规则。<br>4.2 调整请求对象及 JSON 序列化。<br>4.3 校验金额精度和字段边界。<br>4.4 拦截重复 `lineUid`。<br>4.5 完善主体映射和关键日志。<br>4.6 完成新增、更新及异常测试。<br>4.7 完成联调、对账和回滚说明。 | 请求报文与 OneContract 接口文档一致；重复 `lineUid` 和非法数据在发送前被拦截；金额精度、枚举和主体名称正确；批量执行可追溯、可重试且失败不产生错误数据。 |
| 5. 生产环境上线准备 | 5.1 合并合同中间服务代码并构建。<br>5.2 合并 OA 合同相关代码并回归。<br>5.3 合并费控合同相关代码并回归。<br>5.4 配置并验证合同流程节点。<br>5.5 配置合同门户菜单、权限和接入。<br>5.6 切换经销商客户数据源并验证。<br>5.7 创建企微应用授权并验证权限。<br>5.8 接入离职交接合同经办人校验。<br>5.9 完成生产配置、发布演练和上线门禁。 | 各项目和分支以确定的版本完成合并并通过编译和回归；生产配置、密钥、流程、门户、数据源、企微授权均可用；离职交接校验符合业务规则；上线检查表、回滚方案、监控告警和责任人完整。 |
